## ✅ 3. 기획

-회원관리 , 이용자 출입 시간관리, 운동 일지 기록 등의 데이터를 통합적으로 관리 가능한  JDBC 프로그램

-각각의 데이터를 연결시켜 관계된 데이터가 수정되면 같이 수정되도록 무결성 유지 (기본키, 외래키, 데이터 종속 사용)

-상속, 정복은닉, 캡슐화, 재사용 등의 객체지향적 프로그램 설계 

-DB와 직접 접촉하는 DAO, 로직을 처리하는 서비스, 데이터를 관리하는 DTO 등으로 분리하여 책임분할

## ✅ 5. CRUD 요구사항
| 기능       | 설명                  |     |
|------------|-----------------------|------------------
| Create     | 새 데이터 등록         |새 회원 추가  (회원ID, 회원이름, 등록일)
| Read (All) | 전체 데이터 목록 조회  |전체 회원 조회 (회원ID, 회원명)
| Read (One) | 단건 조회 (상세 보기)  |1명 회원 상세 조회(회원정보, 운동일지, 상세운동정보)
| Update     | 기존 데이터 수정       |id값을 입력하여 회원정보 수정
| Delete     | 기존 데이터 삭제       |id값을 입력하여 회원정보 삭제(다른 정보들도 종속되어 삭제됨)     

- ❗❗ **전체 조회 및 상세 조회 시, 연관 테이블과의 조인 결과를 포함한다.**
